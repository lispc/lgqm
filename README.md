# 临高启明世界观推演笔记

本仓库用于整理架空小说《临高启明》（吹牛者等集体创作）的世界观设定，并在此基础上推演科技路线。

## 课题

**主线课题：在小说时间线（1628 年明末海南临高起步）中发展计算机/集成电路技术——步骤、时间线、资源投入、路线、产出。** 后续延伸至硅路线远期推演（至 Win95 级）、设定自洽性场景检验与世界内创作。
