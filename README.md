# 临高启明世界观推演笔记

本仓库用于整理架空小说《临高启明》（吹牛者等集体创作）的世界观设定，并在此基础上推演科技路线。

## 本次课题

**在小说时间线（1628 年明末海南临高起步）中发展计算机/集成电路技术：步骤、时间线、资源投入、路线、产出。**

## 目录

- `notes/01-正典-总体科技与时间线.md` — 正文原著中元老院的科技家底、穿越物资、大事年表、能源/冶金/化工/管理体制
- `notes/02-正典-电子电气与计算.md` — 正文中与电子、通信、计算直接相关的设定（推演的主要锚点）
- `notes/03-同人-电子与计算机设定.md` — 同人作品与论坛讨论中的电子/计算机路线设定（secondary 参考）
- `notes/04-专题-锗集成电路可行性.md` — 深度专题：锗能否做平面工艺/IC（历史证据 + 材料物理 + 低技术工艺包推演）。**修正同人共识的关键文件**
- `notes/05-推演-计算机与集成电路发展路线.md` — **主推演文档**：1637–1660+ 分阶段时间线、资源投入、产出、ARM 库存策略、风险登记
- `notes/06-远期推演-硅路线至Win95级-初估.md` — 硅路线初估稿（含已定的三项方向决策：直奔 CMOS、DRAM 自建、锗硅两线关系）
- `notes/07-详细推演-硅路线至Win95级.md` — **硅路线定稿**：S0–S4 详案、光刻链最优路径（Offner→g线 stepper）、存储/外设/软件线、中国样本教训、关键路径排序
- `notes/08-场景推演-泄密事件.md` — 场景推演：一台锗管收音机漂流到牛顿-胡克时代的欧洲（能测出什么/想不通什么/引发什么 + 自洽性检验）
- `notes/09-澳宋半导体工业史.md` — 世界内视角创作：《澳宋工业通史·电子工业卷》（1637–1700，可直接当同人背景设定用）
- `notes/10-冬夜人声（小说）.md` — 短篇小说：1684 年伦敦，胡克与助手第一次收到临高短波广播（notes/08 场景 5 的展开）
- `notes/90-存疑与冲突清单.md` — 来源冲突、无法核实的点
